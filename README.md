# Gofo-OTWS

美西 OTWS 门户推广数据分析报表 — 需求仓维度分析工具

## 功能

按需求仓维度统计 OTWS 派遣数据，生成 HTML 报表和 Excel 报表。

### 指标说明

| 指标 | 公式 |
|------|------|
| 需求满足率 | 实际线上派遣数 / 发单需求数 |
| 线上派遣率 | 1 − 线下派遣数 / (线下派遣数 + 实际线上派遣数) |

### 报表内容

- 按需求仓分组（CNO.H → LAV.H → SFO.H → SEA.H → DEN → PHX → SAN01）
- 每个需求仓下列出对应供应商及其线上派遣率
- 多供应商需求仓含小计行
- 总体汇总行

## 使用

```bash
python supplier_report_0608_0614.py
```

生成文件：
- `美西OTWS门户推广数据分析报表_供应商维度_0608-0614.html`
- `美西OTWS门户推广数据分析报表_供应商维度_0608-0614.xlsx`

## 数据来源

- 派遣人员名单 Excel（线上派遣明细）
- 临时工派遣 Excel（线下派遣明细）
- 截图（发单需求数）
